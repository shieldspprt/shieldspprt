## Batch LLM Calls with a Bounded Semaphore

Rate limits are a hard ceiling. Fire off fifty calls at once and you hit 429s, retries explode, and latency spikes. Wrap the caller in a semaphore sized to your tier limit and you get predictable throughput with natural backpressure.

```python
import asyncio
from typing import Any

class BoundedLLMClient:
    def __init__(self, client, max_concurrent: int = 10):
        self.client = client
        self.sem = asyncio.Semaphore(max_concurrent)

    async def chat(self, messages: list[dict[str, str]], **kw: Any) -> str:
        async with self.sem:
            resp = await self.client.chat.completions.create(
                messages=messages,
                **kw,
            )
        return resp.choices[0].message.content
```

- Semaphore size equals your tier RPM divided by 60, rounded down. Leave headroom for retries.
- Pair with a token bucket if you also hit TPM limits. The semaphore bounds concurrency, the bucket bounds tokens per minute.
- Works with any async client. No queue infrastructure required, backpressure propagates naturally to callers.
