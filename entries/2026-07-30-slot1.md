Bounded concurrency for parallel tool execution prevents resource exhaustion when an agent fans out many calls at once. A fixed semaphore keeps memory and connection pools predictable while still letting independent tools run in parallel.

```python
import asyncio
from typing import Any, Awaitable, Callable, TypeVar

T = TypeVar("T")

async def bounded_gather(
    tasks: list[Callable[[], Awaitable[T]]],
    concurrency: int = 6,
) -> list[T]:
    sem = asyncio.Semaphore(concurrency)

    async def guarded(coro: Awaitable[T]) -> T:
        async with sem:
            return await coro

    return await asyncio.gather(*[guarded(t()) for t in tasks])
```

- Wrap every tool invocation in a semaphore guard so the agent never exceeds the concurrency ceiling.
- Choose the limit based on your downstream rate limits and connection pool size, not on CPU cores.
- Return results in the original task order so downstream logic stays simple.
