Checkpoint agent state at every tool boundary so a crash or rate-limit pause can resume without repeating work. Persist the minimal snapshot: conversation history, completed tool results, and the next planned action.

```python
import json
import time
from dataclasses import dataclass, asdict
from pathlib import Path
from typing import Any

@dataclass
class AgentCheckpoint:
    step: int
    history: list[dict[str, Any]]
    tool_results: dict[str, Any]
    next_action: str | None
    timestamp: float

def save_checkpoint(path: Path, cp: AgentCheckpoint) -> None:
    tmp = path.with_suffix(".tmp")
    tmp.write_text(json.dumps(asdict(cp)))
    tmp.replace(path)  # atomic on POSIX

def load_checkpoint(path: Path) -> AgentCheckpoint | None:
    if not path.exists():
        return None
    data = json.loads(path.read_text())
    return AgentCheckpoint(**data)

# Usage in the agent loop
checkpoint_path = Path(".checkpoints") / f"{run_id}.json"
cp = load_checkpoint(checkpoint_path)
step = cp.step if cp else 0

```

- Atomic writes (write to `.tmp` then rename) prevent corrupted checkpoints on crash.
- Store only what you need to resume: history, the last tool output, and the next action name. Skip full LLM responses.
- On restart, load the checkpoint and continue from `step` — no duplicate tool calls, no lost progress.
