Event-sourced agent state enables deterministic replay and debugging. Store every decision as an immutable event so you can reconstruct any point in the agent's reasoning loop.

```typescript
type AgentEvent =
  | { type: "llm_call"; prompt: string; model: string; response: string }
  | { type: "tool_call"; name: string; args: unknown; result: ToolResult }
  | { type: "state_change"; path: string; before: unknown; after: unknown }
  | { type: "error"; code: string; message: string; context: Record<string, unknown> };

const eventStore: AgentEvent[] = [];

function emit(event: AgentEvent) {
  eventStore.push({ ...event, timestamp: Date.now() });
}

function replay(events: AgentEvent[]): AgentState {
  return events.reduce((state, event) => {
    switch (event.type) {
      case "llm_call":
        return { ...state, lastPrompt: event.prompt, lastResponse: event.response };
      case "tool_call":
        return { ...state, lastToolResult: event.result };
      case "state_change":
        return setPath(state, event.path, event.after);
      case "error":
        return { ...state, lastError: event };
    }
  }, initialState());
}
```

- Immutable events make post-mortem debugging trivial — replay the exact sequence that led to a failure.
- Append-only storage is cheap; write to a log file or DB table with a request ID for correlation.
- Replay also powers eval harnesses: feed recorded events into a test runner to assert behavior without live LLM calls.
