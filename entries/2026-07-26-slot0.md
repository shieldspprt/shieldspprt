Run async LLM calls in batches with a bounded semaphore to avoid overwhelming providers and hitting rate limits. A semaphore caps concurrent in-flight requests without blocking the event loop.

```python
import asyncio
from typing import List, TypeVar, Callable, Awaitable

T = TypeVar("T")

async def bounded_gather(
    coros: List[Callable[[], Awaitable[T]]],
    max_concurrent: int
) -> List[T]:
    semaphore = asyncio.Semaphore(max_concurrent)

    async def run(coro: Callable[[], Awaitable[T]]) -> T:
        async with semaphore:
            return await coro()

    return await asyncio.gather(*[run(c) for c in coros])


# Usage

    [lambda p=p: call_llm(p) for p in prompts],
    max_concurrent=8
)
```

- Keeps memory flat by limiting simultaneous provider connections.
- Works with any async provider (OpenAI, Anthropic, local models).
- Extend with retries and per-request timeouts inside `run` for production hardening.
