Use a Typed Tool Layer So Agents Never Guess a Schema

Define every tool as a typed class with a static schema method. The registry validates calls at runtime and the agent sees only valid, documented signatures.

```ts
interface Tool<TInput, TOutput> {
  name: string;
  schema: JSONSchema7;
  execute(input: TInput): Promise<TOutput>;
}

class ToolRegistry {
  private tools = new Map<string, Tool<any, any>>();
  register<TIn, TOut>(tool: Tool<TIn, TOut>) {
    this.tools.set(tool.name, tool);
  }
  getSchema(name: string) { return this.tools.get(name)?.schema; }
  async call<TIn, TOut>(name: string, input: TIn): Promise<TOut> {
    const tool = this.tools.get(name) as Tool<TIn, TOut> | undefined;
    if (!tool) throw new Error(`Tool not found: ${name}`);
    const parsed = tool.schema.parse(input);
    return tool.execute(parsed);
  }
}

const getWalletBalance = {
  name: "getWalletBalance",
  schema: z.object({ address: z.string().min(32) }),
  async execute({ address }) {
    const bal = await connection.getBalance(new PublicKey(address));
    return { lamports: bal, sol: bal / 1e9 };
  },
} satisfies Tool<z.infer<typeof getWalletBalance.schema>, { lamports: number; sol: number }>;

registry.register(getWalletBalance);
```

- Register schemas once at startup, validate every call, and fail fast on bad args
- The agent only ever sees correct, typed signatures, no guessing
- Swap implementations without changing the agent prompt
