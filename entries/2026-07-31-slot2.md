Use a sliding window over conversation history to keep agent context bounded and relevant. Drop or summarize turns older than the window, but always preserve the system prompt, the original user request, and the most recent tool results.

```python
from collections import deque
from dataclasses import dataclass
from typing import Any

@dataclass
class Turn:
    role: str
    content: str
    tool_calls: list[dict[str, Any]] | None = None
    tool_results: list[dict[str, Any]] | None = None

class SlidingContext:
    def __init__(self, max_turns: int = 20):
        self.max_turns = max_turns
        self.turns: deque[Turn] = deque()
        self.system_prompt: str = ""
        self.user_request: str = ""

    def add_turn(self, turn: Turn) -> None:
        self.turns.append(turn)
        while len(self.turns) > self.max_turns:
            self.turns.popleft()

    def build_messages(self) -> list[dict[str, Any]]:
        msgs = [{"role": "system", "content": self.system_prompt}]
        if self.user_request:
            msgs.append({"role": "user", "content": self.user_request})
        for t in self.turns:
            msgs.append({"role": t.role, "content": t.content})
            if t.tool_calls:
                msgs.append({"role": "assistant", "tool_calls": t.tool_calls})
            if t.tool_results:
                for r in t.tool_results:
                    msgs.append({"role": "tool", **r})
        return msgs
```

- The window size (e.g., 20 turns) is a token budget proxy. Tune it per model context limit and typical turn length.
- Never drop the last tool result. The agent needs the most recent observation to decide the next action.
- For very long runs, periodically summarize the dropped prefix into a single "context summary" turn and prepend it inside the window.
