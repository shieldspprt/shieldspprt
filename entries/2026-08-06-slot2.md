A request-scoped context carries trace IDs and user identity through every async hop so logs and errors stay correlated without thread-local hacks.

```python
import contextvars
import uuid
from dataclasses import dataclass

request_ctx: contextvars.ContextVar["RequestContext | None"] = contextvars.ContextVar("request_ctx", default=None)

@dataclass
class RequestContext:
    trace_id: str
    user_id: str | None
    started_at: float

def new_context(user_id: str | None = None) -> RequestContext:
    ctx = RequestContext(
        trace_id=uuid.uuid4().hex[:16],
        user_id=user_id,
        started_at=__import__("time").time(),
    )
    request_ctx.set(ctx)
    return ctx

def get_trace_id() -> str:
    return request_ctx.get().trace_id if request_ctx.get() else "no-trace"
```

- `contextvars` propagates automatically across `await` boundaries unlike thread-locals.
- Set the context once at the request entry point (middleware, webhook handler, agent entry).
- Read `get_trace_id()` anywhere in the call chain for structured logs and error reporting.
