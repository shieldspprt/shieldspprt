Graceful degradation keeps your agent useful when the primary LLM provider degrades. Route requests through a fallback chain with strict latency budgets so a slow or failing model never blocks the user.

```typescript
type Provider = { name: string; call: (prompt: string) => Promise<string> };
const CHAIN: Provider[] = [
  { name: "primary", call: callPrimary },
  { name: "fallback-1", call: callFallback1 },
  { name: "fallback-2", call: callFallback2 },
];

async function callWithFallback(prompt: string, budgetMs = 8000) {
  const deadline = Date.now() + budgetMs;
  for (const p of CHAIN) {
    const remaining = deadline - Date.now();
    if (remaining <= 0) throw new Error("budget exhausted");
    try {
      const result = await Promise.race([
        p.call(prompt),
        new Promise<never>((_, r) => setTimeout(() => r(new Error("timeout")), remaining)),
      ]);
      return result;
    } catch (e) {
      console.warn(`provider ${p.name} failed`, e);
    }
  }
  throw new Error("all providers failed");
}
```

- Wrap each provider call in a per-request deadline so a slow model cannot starve the chain
- Log every fallback with the error class so you can tune quotas and alert on real degradation
- Keep the fallback models smaller and cheaper; they only need to be "good enough" to unblock the user
