A request-scoped cache prevents identical in-flight LLM calls from hitting the provider twice. Wrap the call in an async map keyed by the normalized prompt and model; await the first in-flight promise instead of launching a duplicate. The cache lives only for the request lifetime, so memory stays bounded and retries share the same upstream call.

```python
from functools import wraps
from typing import Any, Callable
import hashlib
import json

def request_scoped_llm_cache():
    cache: dict[str, Any] = {}
    in_flight: dict[str, asyncio.Task] = {}

    def key(prompt: str, model: str, **kwargs) -> str:
        payload = json.dumps({"prompt": prompt, "model": model, **kwargs}, sort_keys=True)
        return hashlib.sha256(payload.encode()).hexdigest()[:16]

    def decorator(fn: Callable) -> Callable:
        @wraps(fn)
        async def wrapper(prompt: str, model: str, **kwargs):
            k = key(prompt, model, **kwargs)
            if k in cache:
                return cache[k]
            if k in in_flight:
                return await in_flight[k]
            task = asyncio.create_task(fn(prompt, model, **kwargs))
            in_flight[k] = task
            try:
                result = await task
                cache[k] = result
                return result
            finally:
                in_flight.pop(k, None)
        return wrapper
    return decorator
```

- The cache key normalizes prompt, model, and sampling params so semantically identical calls collide.
- In-flight deduplication shares the await across concurrent callers instead of launching N parallel requests.
- Request scope means the map is discarded when the handler returns, so no eviction policy or memory leak risk.
