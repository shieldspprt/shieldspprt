An eval harness that runs on every PR catches agent regressions before they reach production. Treat agent behavior like any other critical code path.

```python
# tests/agent_evals.py
import pytest
from my_agent import run_agent

EVAL_CASES = [
    ("user asks for wallet balance", "get_balance", {"mint": "So11111111111111111111111111111111111111112"}),
    ("user wants to sweep dust", "sweep_dust", {"threshold_lamports": 1000000}),
    ("user asks to revoke approvals", "revoke_approvals", {"delegate": "delegate_address"}),
]

@pytest.mark.parametrize("prompt,expected_tool,expected_args", EVAL_CASES)
def test_agent_tool_selection(prompt, expected_tool, expected_args):
    result = run_agent(prompt)
    assert result.tool_calls[0].name == expected_tool
    assert result.tool_calls[0].arguments == expected_args
```

- Run evals in CI on every PR to catch tool-selection drift
- Keep eval cases small and deterministic, update them when behavior intentionally changes
- Store the raw LLM response alongside parsed output so failures are debuggable without re-running the model
