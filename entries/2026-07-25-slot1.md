## Prefill the Assistant Message to Steer JSON Output Reliably

LLMs follow the pattern you start. Prefill the assistant message with `{` or `{"key":` and the model completes valid JSON instead of wrapping it in prose or code fences.

```python
from openai import AsyncOpenAI

client = AsyncOpenAI()

async def structured_chat(messages: list[dict[str, str]], schema_hint: str) -> str:
    resp = await client.chat.completions.create(
        model="gpt-4o-mini",
        messages=messages + [{"role": "assistant", "content": schema_hint}],
        max_tokens=500,
        temperature=0,
    )
    return schema_hint + resp.choices[0].message.content

# Usage: prefill with opening brace or a known key
result = await structured_chat(user_messages, '{"action":')
# Result: '{"action": "transfer", "amount": 100, "recipient": "0x123..."}'
```

- Prefill `{"key":` when you know the first key. Prefill `{` when the schema varies.
- Works with any model that respects the assistant prefix. No function-calling schema required.
- Pair with a JSON repair pass (strip trailing commas, close braces) for production resilience.
