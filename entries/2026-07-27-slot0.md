Register Tool Schemas at Startup and Validate Every Agent Call Against Them

When an agent can call arbitrary tools, a hallucinated schema or missing parameter crashes the loop at runtime. Register every tool schema at application startup in a central registry, then validate each agent tool call against that registry before execution. Reject invalid calls with a structured error the agent can retry, instead of a stack trace that ends the turn.

```python
from typing import Any
from pydantic import BaseModel, ValidationError

class ToolSchema(BaseModel):
    name: str
    description: str
    parameters: dict[str, Any]

class ToolRegistry:
    def __init__(self) -> None:
        self._schemas: dict[str, ToolSchema] = {}

    def register(self, schema: ToolSchema) -> None:
        self._schemas[schema.name] = schema

    def validate_call(self, name: str, arguments: dict[str, Any]) -> tuple[bool, str | None]:
        schema = self._schemas.get(name)
        if not schema:
            return False, f"Unknown tool: {name}"
        try:
            # Validate against the JSON Schema using a lightweight validator
            # In production use jsonschema or pydantic-core for full validation
            required = schema.parameters.get("required", [])
            for req in required:
                if req not in arguments:
                    return False, f"Missing required parameter: {req}"
            return True, None
        except Exception as e:
            return False, f"Validation error: {e}"

registry = ToolRegistry()

# At startup, register all tools
registry.register(ToolSchema(
    name="read_file",
    description="Read a file from disk",
    parameters={
        "type": "object",
        "properties": {"path": {"type": "string"}},
        "required": ["path"],
    },
))
```

- Central registry prevents schema drift between the agent's prompt and actual tool implementations
- Validation at call time catches hallucinated parameters before they hit downstream code
- Structured validation errors let the agent self-correct in the next turn instead of crashing the loop
