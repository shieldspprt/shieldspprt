Structured error envelopes make agent failures debuggable. Wrap every tool call result in a consistent shape so you can trace failures across steps without guessing.

```typescript
type ToolResult<T> =
  | { ok: true; value: T }
  | { ok: false; error: { code: string; message: string; cause?: Error } };

async function callTool<T>(name: string, args: unknown): Promise<ToolResult<T>> {
  try {
    const value = await registry.execute(name, args);
    return { ok: true, value };
  } catch (e) {
    const err = e as Error;
    return {
      ok: false,
      error: {
        code: err.name ?? "ToolError",
        message: err.message,
        cause: err,
      },
    };
  }
}
```

- Check `result.ok` before accessing `result.value` — forces callers to handle the error case.
- Include a stable `code` so upstream logic can switch on failure types (rate-limit, auth, validation).
- Attach the original `cause` for stack traces; log the envelope at the agent loop level for a complete audit trail.
