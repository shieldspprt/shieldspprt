Stream Tool-Call Results to the Client Instead of Buffering the Full Response

When an agent calls tools, the results often arrive in chunks. Buffering everything until the final tool returns adds latency the user perceives as "waiting for the AI." Stream each tool result as a server-sent event or WebSocket frame so the UI renders partial progress immediately.

```python
async def stream_agent_run(user_msg: str, ws: WebSocket):
    async for event in agent.run_stream(user_msg):
        if event.type == "tool_call":
            await ws.send_json({"type": "tool_start", "tool": event.tool, "args": event.args})
        elif event.type == "tool_result":
            await ws.send_json({"type": "tool_done", "tool": event.tool, "result": event.result})
        elif event.type == "llm_delta":
            await ws.send_json({"type": "token", "text": event.delta})
        elif event.type == "final":
            await ws.send_json({"type": "complete", "text": event.text})
            break
```

- Each tool result ships the moment it resolves, no buffering
- The frontend can show a live log of tool calls while the agent thinks
- Keeps the connection alive so load balancers and proxies do not terminate idle streams
