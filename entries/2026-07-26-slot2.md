Use a Request-Scoped Dedupe Cache for Identical In-Flight LLM Calls

When multiple incoming requests trigger identical LLM prompts concurrently, deduplicate the call at the request scope using a short-lived in-memory map keyed by the prompt hash. Await the single in-flight promise and fan out the result to all waiters. This cuts provider latency and token spend without needing a durable cache layer.

```python
import asyncio
import hashlib
from typing import Any, Callable, Awaitable

_inflight: dict[str, asyncio.Future] = {}

async def deduped_llm_call(prompt: str, call: Callable[[], Awaitable[str]]) -> str:
    key = hashlib.sha256(prompt.encode()).hexdigest()[:16]
    if key in _inflight:
        return await _inflight[key]
    fut = asyncio.create_task(call())
    _inflight[key] = fut
    try:
        return await fut
    finally:
        _inflight.pop(key, None)
```

- Deduplicates identical prompts that arrive within the same event-loop tick window
- No TTL or eviction policy needed because the future resolves and the key is deleted
- Works for both streaming and non-streaming calls; wrap the streaming iterator the same way
