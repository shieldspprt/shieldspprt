Batch database writes from agent tool calls into a single transaction to reduce round trips and avoid partial commits on failure.

```ts
async function executeToolCalls(calls: ToolCall[], db: Database) {
  const results = await Promise.all(
    calls.map(c => c.handler(c.args))
  );

  await db.transaction(async tx => {
    for (const [i, call] of calls.entries()) {
      await tx.insert(toolCallLog).values({
        callId: call.id,
        name: call.name,
        args: call.args,
        result: results[i],
        status: "success",
      });
    }
  });
}
```

- One transaction commits all tool-call logs or none, so retries never leave half-written state.
- `Promise.all` runs handlers in parallel, the transaction batches the writes, latency stays low.
- Wrap the whole thing in a retry with idempotency keys on the log table to survive transient DB blips.
