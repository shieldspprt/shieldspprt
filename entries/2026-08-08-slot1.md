Version prompt templates and log the rendered prompt so evals can reproduce exact model inputs.

```python
from string import Template
from dataclasses import dataclass
from datetime import datetime
import hashlib
import json

@dataclass
class RenderedPrompt:
    template_name: str
    template_version: str
    rendered_text: str
    variables: dict
    rendered_at: str
    content_hash: str

def render_prompt(template_name: str, template_version: str, template_text: str, variables: dict) -> RenderedPrompt:
    rendered = Template(template_text).safe_substitute(variables)
    content_hash = hashlib.sha256(rendered.encode()).hexdigest()[:16]
    return RenderedPrompt(
        template_name=template_name,
        template_version=template_version,
        rendered_text=rendered,
        variables=variables,
        rendered_at=datetime.utcnow().isoformat() + "Z",
        content_hash=content_hash,
    )

def log_rendered_prompt(rendered: RenderedPrompt, log_path: str = "logs/rendered_prompts.jsonl"):
    with open(log_path, "a") as f:
        f.write(json.dumps(rendered.__dict__) + "\n")
```

- Version every prompt template with a semantic version and store templates in version control.
- Log the fully rendered prompt with its variable values and a content hash so evals can replay the exact input.
- Hash the rendered text to detect when template or variable changes silently shift model behavior.
