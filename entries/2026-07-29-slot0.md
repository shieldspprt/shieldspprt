Use a correlation ID on every LLM call so retries and logs are traceable end to end.

```ts
async function callLLM(messages: Message[], correlationId: string) {
  const response = await fetch("/api/llm", {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
      "X-Correlation-ID": correlationId,
    },
    body: JSON.stringify({ messages }),
  });
  return response.json();
}

// Middleware extracts the correlation ID and adds it to every log line
app.use((req, res, next) => {
  const cid = req.header("X-Correlation-ID") ?? crypto.randomUUID();
  req.correlationId = cid;
  res.setHeader("X-Correlation-ID", cid);
  logger.info({ correlationId: cid }, "request start");
  next();
});
```

- Attach the same ID to the outbound LLM request, the provider webhook, and any downstream tool calls
- Structured logs with the correlation ID let you stitch a full trace in one query
- Retries automatically inherit the ID so duplicate attempts are obvious in logs
